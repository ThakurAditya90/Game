Go to the repository root directory, click **Add file** in the top-right corner, select **Create new file**, and name it `index.html`. Paste your HTML code into the editor, scroll to the bottom, write a commit message (e.g., `Add index.html`), and click **Commit changes...**. To view the rendered page in a browser: 1. Go to **Settings** > **Pages**. 2. Under **Build and deployment**, set the **Branch** to `main` (or `master`) and folder to `/ (root)`. 3. Click **Save**. GitHub will generate a live URL (e.g., `https://username.github.io/repository-name/`) to view your `index.html`.
